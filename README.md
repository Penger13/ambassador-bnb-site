# Ambassador B&B and Inn Next Door

A cozy Victorian bed & breakfast website for Ambassador B&B in Stratford, Ontario.

## Features

- 8 room pages (4 B&B rooms + 4 Inn suites)
- Online booking integration
- Contact form with Netlify Forms
- Responsive design
- Policies page

## Tech Stack

- HTML5
- CSS3 (custom)
- JavaScript (vanilla)
- Netlify Forms

## Live Site

[View the live site](https://YOUR-SITE-NAME.netlify.app)

## Local Development

1. Clone the repository
2. Open `index.html` in your browser
3. Or use VS Code Live Server for a local server

## Deployment

This site is deployed automatically via Netlify on every push to the `main` branch.
